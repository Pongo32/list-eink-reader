# «Лист»: инструкция по исправлению дизайна

Цель: приблизить интерфейс к логике Kindle (по мотивам, без копирования шрифта, иконок и названий Amazon) и убрать «серую кашу», которая сейчас видна на экране устройства (Faust 3, 6", E-Ink).

Основано на: код `ru.reader.eink` (`MainActivity`, `ReaderActivity`, `styles.xml`, `strings.xml`, манифест), ваши фото библиотеки и чтения, референс Kindle.
Номера строк даны по текущей версии репозитория, они могут сдвинуться.

## 2. Целевые принципы (из Kindle, адаптировано под E-Ink)

1. **Страница чтения чистая.** Постоянно видны только: текст, и одна тонкая нижняя строка («Страница N из M» слева, процент справа). Всё остальное появляется по касанию верха/центра.
2. **Меню поверх страницы, а не в потоке верстки.** Панели рисуются как слой над страницей (`FrameLayout`), чтобы размер страницы не менялся. Это важно: сейчас EPUB-вёрстка берёт размер из `pageImage` (`prepareDocument`, 446–451, и 608–614), и любое изменение его размера вызовет переразметку и сбой позиции.
3. **Контраст вместо цвета.** Белый фон, чёрный текст, чёрные 2 dp рамки, нажатое состояние = инверсия (чёрный фон, белый текст).
4. **Никаких анимаций, теней с размытием, полупрозрачности.**
5. **Крупные цели касания ≥ 48 dp**, текст интерфейса ≥ 14 sp, вторичный текст не светлее `#444444`.
6. **Скевоморфизм дозированно:** лента-закладка, «листок» книги с загнутым уголком вместо серого прямоугольника, двойная рамка у шторок. Без градиентов.

## 3. Шаг 0 (основа): дизайн-токены и общие компоненты

Создать `Ui.java` (пакет `ru.reader.eink`), перенести в него все цвета, размеры и фабрики кнопок. Оба Activity должны брать значения оттуда.

### 3.1 Токены

```java
final class Ui {
    // Палитра: только 5 уровней серого. Тёплых оттенков нет.
    static final int WHITE     = 0xFFFFFFFF; // фон всего
    static final int INK       = 0xFF000000; // основной текст, рамки
    static final int SECONDARY = 0xFF444444; // вторичный текст (светлее нельзя)
    static final int HAIR      = 0xFF8A8A8A; // тонкие разделители, неактивное
    static final int FILL      = 0xFFE6E6E6; // ЕДИНСТВЕННАЯ серая заливка (подложка шторки, трек)

    // Размеры в sp / dp
    static final int TEXT_TITLE = 30;   // «Лист»
    static final int TEXT_BODY  = 16;   // основной интерфейс
    static final int TEXT_SMALL = 14;   // подписи, минимум
    static final int LINE       = 2;    // dp, основная линия
    static final int LINE_THICK = 3;    // dp, выбранное
    static final int TOUCH      = 48;   // dp, минимальная цель
    static final int RADIUS     = 6;    // dp
}
```

### 3.2 Кнопка с состояниями (замена `smallButton()` и `button()`)

```java
static GradientDrawable box(Context c, int fill, int stroke) {
    GradientDrawable d = new GradientDrawable();
    d.setColor(fill);
    d.setStroke(dp(c, LINE), stroke);
    d.setCornerRadius(dp(c, RADIUS));
    return d;
}

static void styleButton(Button b) {
    Context c = b.getContext();
    StateListDrawable bg = new StateListDrawable();
    bg.addState(new int[] {android.R.attr.state_pressed}, box(c, INK, INK));      // нажато: инверсия
    bg.addState(new int[] {-android.R.attr.state_enabled}, box(c, WHITE, HAIR));  // недоступно
    bg.addState(new int[] {}, box(c, WHITE, INK));                                // обычное
    b.setBackground(bg);                                                          // API 16+, у нас minSdk 19
    b.setTextColor(new ColorStateList(
        new int[][] {{android.R.attr.state_pressed}, {-android.R.attr.state_enabled}, {}},
        new int[] {WHITE, HAIR, INK}));
    b.setAllCaps(false);
    b.setTextSize(TEXT_BODY);
    b.setMinHeight(dp(c, TOUCH));
    b.setMinimumHeight(dp(c, TOUCH));
}
```

Вместо `setBackgroundColor(...)` теперь везде `Ui.styleButton(...)`.

### 3.3 Остальные компоненты, которые нужно сделать один раз

| Компонент | Как сделать | Где используется |
|---|---|---|
| `Ui.divider(ctx)` | `View` высотой 1 dp, цвет `HAIR` | между блоками библиотеки, строки закладок |
| `TabBar` (вкладки с подчёркиванием) | `LinearLayout` из `TextView` + `View` 3 dp снизу; активная: жирный, чёрное подчёркивание; неактивная: `SECONDARY`, без подчёркивания | фильтры «Все / Читаю / Прочитано» |
| `IconButton` | `View` 48×48 dp с `onDraw` (Path/Canvas, как уже сделано в `BookmarkFlagView`); состояние pressed = инверсия | «+», поиск, меню ⋮, «←», Aa |
| `SegmentedScale` | `View` из N сегментов 22×10 dp, залитые до выбранного, цифра над текущим, слева «−», справа «+» | размер шрифта в шторке «Аа» |
| `Sheet` (шторка) | `LinearLayout` с белым фоном, рамкой 2 dp сверху, «ручкой» 40×4 dp по центру | «Аа», закладки |

Иконки только через Canvas/PNG: `VectorDrawable` XML на API 19 не работает.

### 3.4 Шрифты и стили

- В `styles.xml` оставить `Theme.Holo.Light.NoActionBar`, но задать `android:windowBackground = #FFFFFF`, `android:textColorPrimary = #000000`, `android:textColorSecondary = #444444`.
- Для заголовков («Лист», названия книг, название главы) использовать **один** встроенный книжный шрифт (подмножество кириллицы, до 200 КБ) через `Typeface.createFromAsset`: PT Serif или Literata (OFL). `Typeface.SERIF` на старых устройствах даёт разный результат.
- Для интерфейса оставить системный `sans`, но только **Regular и Bold**, без `Light` и курсива.

## 5. Экран «Чтение» (`ReaderActivity`)

### 5.1 Целевая раскладка

Постоянно на экране (покой):

```

│                           ▮   │  ← ленточка закладки (только если страница в закладках)
│    текст книги / страница PDF │

│ Страница 51 из 588       8%   │  ← 14 sp, SECONDARY, фиксированная высота 28 dp

```

После касания в верхней части страницы (слой поверх, фон белый, без прозрачности):

```

│ ←  МВА в картинках…   Aa  ≡  ▯│  ← верхняя панель 56 dp: назад, название, Aa, закладки, лента
├───────────────────────────────┤
│  (страница)                   │
├───────────────────────────────┤

└───────────────────────────────┘
```

### 5.2 Правки по пунктам

1. **Каркас без перестройки вёрстки** (`buildScreen`, 201–391).
   - Корень остаётся `FrameLayout`. Внизу `LinearLayout`: `pageImage` (вес 1) и фиксированная нижняя строка 28 dp. Верхний и нижний слой-«меню» добавить в корневой `FrameLayout` **поверх**, видимость `GONE`/`VISIBLE`.
   - **Размер `pageImage` не должен меняться** при показе меню, иначе запустится переразметка EPUB (`prepareDocument`, `changeEpubFontSize`). Нужны постоянные внутренние отступы страницы (верх 12 dp, низ 4 dp, бока 20 dp) через `setPadding` у `pageImage`.
   - Фон меню строго белый + рамка 2 dp: никакой прозрачности, иначе текст страницы просвечивает и грязнится.

2. **Зоны касания** (строки 280–300, сейчас 35% / 65% с мёртвой серединой).

   ```java
   float x = event.getX() / Math.max(1, view.getWidth());
   float y = event.getY() / Math.max(1, view.getHeight());
   if (y < 0.12f || y > 0.88f) {          // верх и низ: показать/скрыть меню
       toggleOverlay();
   } else if (x < 0.33f) {                // левая треть: назад
       movePage(-1);
   } else {                               // правые 2/3: вперёд
       movePage(1);
   }
   ```
   Проверку нажатия на картинку EPUB (`findEpubImageAt`) оставить до этого блока. При открытом меню первое касание внутри страницы только закрывает его.

3. **Верхняя панель** (замена строк 210–268).
   - Слева «←» (иконка 48 dp, `finish()`), затем название 16 sp серифным (1 строка, обрезка многоточием), справа иконки: **Aa** (только для EPUB), **≡** (список закладок), **закладка-лента**.
   - `A-`, число и `A+` из панели убрать, они переезжают в шторку «Аа».
   - Высота 56 dp, нижняя граница 2 dp чёрная.

4. **Шторка «Аа»** (новая, для EPUB; `epubFontControls` и `changeEpubFontSize` уже есть, 230–259, 585–660).
   - Снизу поднимается панель высотой ~35% экрана: сверху «ручка», рамка 2 dp.
   - Одна строка **«Размер»**: `−` (48×48), шкала `SegmentedScale` из 13 сегментов (8…32 шаг 2, как `MIN/MAX_EPUB_FONT_SIZE` и `EPUB_FONT_SIZE_STEP`), `+`. Над выбранным сегментом цифра.
   - Страница над шторкой остаётся видимой и пересчитывается (как у Kindle). Пока идёт переразметка (`epubFontRelayoutPending`) показывать в шторке «Перестраиваем страницы…» (строка `epub_font_reflowing` уже есть).
   - Для PDF кнопку Aa скрыть (или заменить на переключатель «Оригинал / Адаптированный», если такой режим появится).
   - Следующий шаг (по желанию): плитки «Поля» (3) и «Интервал» (3) с пиктограммами строк.

5. **Нижняя строка покоя** (замена футера 305–347).
   - Удалить большие кнопки ‹ ›: листание уже идёт касаниями и аппаратными клавишами.
   - Строка 28 dp: слева «Страница 51 из 588» (`book_page_label`), справа процент. Цвет `SECONDARY`, 14 sp.

## 6. Поведение, свойственное E-Ink

- **Без анимаций:** никаких `animate()`, `LayoutTransition`, fade. Показ/скрытие панелей мгновенное (`setVisibility`).
- **Нажатие = инверсия** (см. 3.2). Это единственная обратная связь на таком экране.
- **Чёткие границы перерисовки:** панели непрозрачные, с рамкой, чтобы обновлялась только их область.
- **Полное обновление экрана** (против призраков) раз в N страниц: вендорный API (Onyx) подключать только как необязательный слой с безопасным запасным вариантом. Не завязываться на него в дизайне.
- **Одна заливка серым.** Если нужна ещё одна ступень, использовать штриховку линиями, а не новый серый.

## 8. Как проверить результат на устройстве

Снять те же 2 экрана (библиотека и чтение) и сравнить:

- [ ] На библиотеке нет клавиатуры после запуска; поиск раскрывается по значку.
- [ ] Любая кнопка отличима от фона с расстояния ~40 см; нажатая кнопка инвертируется.
- [ ] Нет текста светлее `#444444` и мельче 14 sp.
- [ ] Все элементы касания не меньше 48×48 dp.
- [ ] В шапке библиотеки только «Лист» и 2 иконки; до первой книги не больше ~30% высоты экрана.
- [ ] У карточек книг нет дублирующихся названий; видны обложки либо аккуратный «листок».
- [ ] Читалка в покое: только текст и одна нижняя строка; меню появляется по касанию верха/низа и не меняет разбивку текста EPUB (проверить: открыть меню, закрыть, номер страницы и первая строка не изменились).
- [ ] Закладка ставится одним касанием по ленте; список закладок открывается отдельной иконкой.
- [ ] Размер шрифта EPUB меняется в шторке «Аа», страница сверху обновляется сразу.
- [ ] Нет анимаций и полупрозрачных слоёв.
