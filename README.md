# Лист — читалка для E-Ink

**Лист** — простая читалка для PDF и EPUB на старых Android-устройствах с экраном E-Ink. Приложение открывает книги из памяти устройства, запоминает место чтения и старается сделать PDF удобнее для небольшого экрана.

## Что умеет

- Находит PDF и EPUB в доступных общих папках; книгу также можно выбрать кнопкой «Добавить» или открыть из файлового приложения.
- Ищет книги по названию и показывает все книги, те, которые вы читаете, или уже прочитанные.
- Запоминает страницу, закладки и отдельный размер шрифта для каждой книги.
- Позволяет менять размер шрифта EPUB кнопками A− и A+ и увеличивать изображения в книге.
- Показывает исходную страницу PDF сразу, а адаптацию страниц выполняет в фоне. Если адаптация не удалась, можно продолжить чтение оригинала.
- Поддерживает перелистывание кнопками на экране и аппаратными клавишами устройства.

## Как пользоваться

1. Установите приложение и откройте его. При установке подтвердите доступ к общим файлам, если система покажет запрос.
2. Выберите книгу из библиотеки или нажмите **«Добавить»**, чтобы найти PDF или EPUB. Кнопка **«Обновить»** повторно просканирует доступные папки.
3. Нажмите на книгу, чтобы читать. Стрелки или аппаратные клавиши перелистывают страницы; кнопка **A− / A+** меняет размер шрифта EPUB.
4. Нажмите на значок закладки, чтобы сохранить текущую страницу или открыть список закладок. Вернуться к последней книге можно из библиотеки.

## Сборка и установка

Это исходный код приложения; готовый APK в репозиторий не входит. Для сборки нужны JDK 17, Android SDK (API 35), Android NDK 23.2.8568313 и CMake 3.22.1.

Из корневой папки проекта в PowerShell:

```powershell
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
.\android\gradlew.bat -p .\android assembleDebug
```

APK появится в `android\app\build\outputs\apk\debug\app-debug.apk`. Установить его на подключённое устройство с включённой отладкой по USB можно командой:

```powershell
adb install -r .\android\app\build\outputs\apk\debug\app-debug.apk
```

Сборка настроена для **ARMv7 (`armeabi-v7a`)**. Приложение требует Android **4.4 или новее** (API 19); версия приложения — **0.1.0**.

## Статус и ограничения

Проект находится в разработке и прежде всего предназначен для старых E-Ink-устройств. На подключённом устройстве проверялись отдельные сценарии на искусственно созданных PDF и EPUB. Это не подтверждает качество на обычных книгах или совместимость со всеми устройствами.

Пока не подтверждены на реальных книгах читаемость PDF после адаптации, скорость и расход памяти/батареи; также не проверены защищённые паролем PDF, аппаратные клавиши и специальные функции обновления E-Ink-экрана на других моделях. Для защищённых паролем документов поддержки нет. Установка на Android новее минимальной версии возможна, но совместимость с конкретными устройствами отдельно не гарантируется.

Подробности реализации, сборки и выполненных проверок приведены в [`android/README.md`](android/README.md).

## Файлы и конфиденциальность

Книги открываются на устройстве. Исходный файл не изменяется: для чтения приложение использует свою временную копию, а адаптированные страницы PDF хранит в ограниченном кэше приложения. Прогресс чтения, закладки и размер шрифта сохраняются локально. В Android-манифесте запрашивается доступ на чтение общих файлов; разрешение на сетевой доступ приложению не задано.
